What we're proposing

One page that lists every DMO dataset, with what it contains, how often it changes, when it last changed and the formats it comes in. Each entry goes straight to the data, and the API is documented here too.

Why

The Data section today is a list of twelve links, each leading to an introduction page and then to a report form. So the data is three clicks from the menu, and nowhere on the way does it say when anything was last updated. For people who use the site every day, the update times are often the whole point.

Report codes are the DMO's own. Descriptions, dates and formats are as proposed, not as published today.

Gilt market data

DMO data

Data on gilts, Treasury bills, gilt operations and lending to local authorities. Every dataset is free to use under the Open Government Licence.

Find a dataset

    BehaviourSearch matches names, descriptions and report codes, so people who already know "D1A" can still type it. Gilts in issue, the results table, PWLB rates and the remit are linked to the other prototypes.

    Use the data API

    Every dataset is available as JSON or CSV at a stable address. No key is needed.

    GET /api/gilts-in-issue?date=2026-09-30

    Returns one record per gilt: name, ISIN, type, coupon, redemption date, nominal in issue.
