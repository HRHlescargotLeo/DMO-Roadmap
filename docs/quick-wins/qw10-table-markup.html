Quick win 10 of 23 · Mark up the Publications table properly

What we're proposing

Rebuild the Publications table with header cells, a caption and column scopes. It looks almost the same; it sounds very different.

Why

The header row is built from ordinary cells, and the table has no caption. A screen reader user moving along a row hears the values without the column names, so "96.8KB" and "30-September-2026" arrive with no context.
