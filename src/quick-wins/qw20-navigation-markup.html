Quick win 20 of 23 · Plain navigation markup

What we're proposing

Mark up the main menu as a plain list of links inside a navigation landmark, and give the section menu's toggles their section name with an expanded or collapsed state.

Why

The main menu uses the ARIA "tree" role, which screen readers announce as a tree view, the pattern used for file browsers. The section menu toggles read out as "Toggle Gilt Market button expanded", with the state written into the name. Neither stops anyone using the site, but both make it slower and stranger than it needs to be.
